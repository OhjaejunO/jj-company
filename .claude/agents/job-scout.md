## 평가 기준 (공고당)
- **1차 출처(원공고) 접속 확인 실패 또는 애그리게이터만 확보된 공고는 적합도 부여 금지** — "확인 불가" 섹션으로 분리하고, 원공고 URL 확보는 **"확인 필요" 섹션에 남긴다.**
  - **단, WebFetch 의 404/403 을 곧바로 "공고 소멸"로 읽지 마라.** 도구 접근 실패(UA 차단 등)일 수 있다 — 실제로 원티드 공고가 WebFetch 로는 404 인데 브라우저·웹검색으로는 정상 조회된 사례가 있다.
  - 접속이 실패하면 **웹검색 스니펫으로 교차 확인**하라. 회사·직무·모집 상태가 검색 결과에서 확인되면 평가 대상으로 둔다.
  - **이틀 연속 접속·웹검색 양쪽 다 실패한 경우에만** "확인 불가"로 분류한다.
- **마감일이 조회 시점 기준 경과한 공고는 적합도와 무관하게 판단 대상에서 제외한다** — "마감" 섹션으로 분리하고, 재공고 확인은 "확인 필요" 섹션에 남긴다.
- 적합도 상/중/하 + 한 줄 근거 (JD 요구 ↔ JJ 자산 매칭)
- 마감일, 채용 형태, 공고 URL
- JJ-harness/토망치랩/factory-space 중 뭘 내세울지 1개 추천
