# 기계 3종 — 가공기 → 검수기 교체 검토

**상태**: ⚠️ **`SCOPE.md` 부재로 반쪽 검토.** JJ 승인 전 확정 금지.

---

## 먼저 — 전제가 비어 있다

지시는 "`SCOPE.md` 보정: 기계 3종 중 **가공기** 대신 **검수기**(불량 판별→폐기 라인) 채택 검토"였다. 그런데 **`SCOPE.md` 가 이 레포에 없다.** `projects/gamebuilders/` 에는 오늘 만든 `요강.md`·`플랜.md`·`컨셉후보.md` 뿐이고, 작업장·운영 서버·git 이력 어디에도 `SCOPE.md` 나 기계 3종 정의가 없다.

**따라서 "기계 3종"이 무엇인지 모른다.** 나머지 2종을 모르는 채로 총량 비교를 하면 그건 추측이다. 아래는 **가공기 ↔ 검수기 두 기계만 놓고 본 일반 비교**이며, 3종 전체 스코프 총량 판단은 `SCOPE.md` 를 받은 뒤에 해야 한다.

## 구현 난이도 비교 (스코프 총량 불변 가정)

두 기계는 **상태 기계의 모양이 다르다.** 가공기는 `입력 → 변환 → 출력`의 1:1 파이프라인이라 아이템 타입 테이블 하나와 처리 시간만 있으면 돌아간다. 반면 검수기는 `입력 → 판정 → 분기(통과/폐기)`라서 **출력이 둘로 갈리고, 폐기 라인이라는 두 번째 경로가 맵 위에 실제로 존재해야 한다** — 즉 라인 배치 퍼즐의 공간 요구가 늘고, 플레이어가 폐기물을 어디로 보낼지까지 설계해야 한다. 코드 난이도 자체는 분기 하나 추가 수준이라 큰 차이가 아니지만, **레벨 디자인 부담은 눈에 띄게 커진다.** 대신 얻는 것이 분명하다: 가공기는 "옮기면 바뀐다"로 끝나 긴장이 없는데, 검수기는 **불량률이라는 실패 축**을 만들어 최적화 퍼즐에 목표(불량을 줄여라)와 손실(폐기 비용)을 동시에 준다. 심사 기준으로 보면 Playability(긴장 생성)와 Originality(흔한 컨베이어 퍼즐과의 차별) 두 축에서 유리하고, 대가는 8/15 게이트까지 만들어야 할 레벨이 하나 더 복잡해진다는 것이다.

**판단**: 스코프 총량이 정말 불변이라면 **검수기 쪽이 값어치가 크다.** 다만 그 "총량 불변"은 나머지 2종이 무엇인지 알아야 검증되고, 지금은 검증할 수 없다.

2. 위 판단을 받아들일지 결정 (승인 시 `SCOPE.md` 에 반영)
