### Day 5 (2026-08-14) — 계획

**1. JJ 수동 플레이테스트 (전 레벨) → 피드백 목록화**

`game/index.html` 을 브라우저로 열어 L1~L5 를 직접 플레이한다. **자동 검증이 못 하는 것만 본다** — 해답이 떠오르는가 / 조작이 답답하지 않은가 / 난이도가 순서대로 오르는가 / 어디서 막히고 왜 막히는지 화면이 알려주는가.

피드백은 **레벨별로 한 줄씩** 적는다. "재미없다"가 아니라 **"어디서 무엇을 하다가"** 를 남긴다 — 그래야 고칠 지점이 나온다.

- ⚠️ 이미 나온 검토 대상 1건: **L3 코너 수가 L2보다 낮다**(5 → 1). 난이도 축이 라우팅에서 처리량으로 바뀐 결과인데, 플레이 감각으로 후퇴처럼 느껴지는지 확인한다.

**2. 피드백 반영 + 튜토리얼 텍스트 (L1 진입 흐름)**

지금 L1 은 힌트 문단 하나가 옆 패널에 있을 뿐이다. **처음 여는 사람이 무엇부터 눌러야 하는지 모른다.** L1 진입 시점에 단계별 안내를 붙인다.

- 새 메카닉을 만들지 않는다 — **텍스트와 표시만으로** 푼다 (스코프 락).
- 최소 3단계: ① 소스에서 검수기까지 이어라 ② 검수기 정상 출구를 싱크로 ③ **불량 출구를 폐기로 — 안 하면 라인이 막힌다**
- ③이 이 게임의 핵심이므로 여기서 한 번은 막혀보게 두는 편이 낫다.

**3. 폴리싱 착수 — 사운드·이펙트 (스코프 락 내)**

`SCOPE.md` 가 사운드를 **"후순위"** 로 두었지 금지하지 않았다. 코어가 확정됐으니 착수한다.

- 최소 세트: 벨트 설치 / 정상품 싱크 도달 / **불량품 싱크 유입(실패 피드백)** / 클리어
- **단일 HTML + 정적 호스팅 범위를 벗어나지 않는다** — 외부 CDN·라이브러리 금지, 파일은 리포에 둔다
- 음소거 토글을 같이 넣는다. 심사자가 소리 없이 볼 수 있어야 한다

**게이트**: 8/20 기능 동결까지 6일. **Day 5 안에 플레이테스트 피드백이 안 나오면 폴리싱을 뒤로 미루고 피드백을 먼저 받는다** — 재미가 확정 안 된 상태의 폴리싱은 버려진다.
