# 사람이 내린 결정 (Codex 4문항 재료)

**용도**: 심사 기준 **Codex Collaboration** 의 4문항 중 "사람이 직접 결정한 부분" 답변 재료.
**규칙**: 개발하면서 **그때그때 한 줄씩** 쌓는다. 나중에 몰아 쓰면 기억으로 지어내게 되고, 그건 심사에 낼 글이 아니다.

**형식**: `YYYY-MM-DD | 결정 | 대안 | 왜 사람이 정했나`

또 하나의 용도 — 요강의 **기존 프로젝트 활용 조항**("챌린지 기간 동안 새롭게 개발된 내용을 명기") 대응 근거다. 기존 자산을 가져다 쓴 지점과 새로 만든 지점을 여기서 가른다.

| 2026-08-13 | **시뮬레이션을 화면에서 분리** (`sim.js` 신설, `game.js`는 입력·렌더만) | 기존 단일 파일 유지 | 레벨이 5개가 되면 "클리어 가능한가"를 눈으로 확인할 수 없다. **검증이 실제 게임 로직과 같은 코드를 써야 증명이 성립**하므로, 브라우저 없이 돌릴 수 있는 형태로 갈랐다 |
| 2026-08-13 | **레벨마다 참조 해답을 코드에 넣고 헤드리스로 클리어를 실증** | 직접 플레이해 보고 판단 | 감으로 "될 것 같다"는 심사 제출물의 근거가 못 된다. 해답을 데이터로 박아두면 레벨을 수정했을 때 검증이 깨져서 **바로 드러난다** |

| 2026-08-13 | **검증에 "폐기 라인 반증 테스트"를 포함** | 클리어 확인만 | `SCOPE.md` 는 "폐기 경로를 안 만들면 클리어가 불가능하다"를 게임의 긴장으로 선언했다. **그 주장이 실제로 참인지 확인하지 않으면 선언일 뿐이다.** 폐기 벨트만 걷어내고 돌려서 전 레벨이 막히는 것을 확인했다 |
