# 유통 변환 워커 — 양식 4 · 양식 1호 · 층: 제안 · 상태: 설계 (2026-08-26)

**JOB** 발행 완료 편 1건을 받아 Threads 캐러셀 20장 · X 4장(+킷 링크는 답글로 분리) **초안**을 만들어 JJ 발행 게이트에 넘긴다.

**TRIGGER** 사람 호출 — 발행로그 상태 `발행` 확정 후 JJ 가 «변환» 지시. 스케줄 아님(전제: Threads 계정 등록 — JJ 대기, `04_운영/계정등록_절차서_JJ용.md`).

**INPUTS** (정본/사본 표기)
- 편 폴더 `01_발행완료/epNN_*/` — `build_epNN.py`(CARDS·COVER·KIT 선언, 정본) · `_facts.py`(정본) · `caption.txt`·`pinned_comment.txt`(정본) · 덱 PNG/MP4(실물)
- SKILL §4.1(어미) · §5(캡션) · §6.1(3단 위계) · v3.52 편수/게시물 층 — 절 참조만
- `유통확장_설계안.md` §1·§2 (채널 제약: Threads 20장 · X 4장 · 링크 단가)

**PROCESS**
1. 편 선언을 읽어 «주장 목록» 을 만든다 — 카드 헤드라인·핵심줄·본문 각 줄이 한 주장.
2. **소스 맵**: 주장마다 `_facts.py` 키를 붙인다 (`주장 → FACTS 키 → Verified`). 키가 없는 주장은 `Unverified` 로 표기하고 변환본에서 **뺀다**(덜 싣는 건 자유).
3. Threads 20장: 카드 순서 유지, 카드당 1~2장. 길이 압축은 «문장 삭제» 로만 — 어미·수치·고유명사는 손대지 않는다. 표지 훅 → 1장 · 킷 CTA → 마지막 장.
4. X 4장: 표지 + 핵심 3장. 킷 링크는 **본문에 넣지 않고 답글 1건**으로 분리(링크 단가 — 설계안 §2).
5. 변환본을 `reports/<날짜>_dist_epNN.md` 로 쓴다(복붙 세트 형식 — Threads 블록 · X 블록 · 답글 블록 · 소스 맵 표).
6. GATE 를 돌려 `STATUS:` 를 찍는다.

**OUTPUT** `reports/<yyyy-MM-dd>_dist_epNN.md` — 정본 쓰기 없음(발행로그 채널 열은 JJ 가 발행 후 기입).

**RULES — 금지 자리**
- 게이트 판정 해석 금지(값만) · 조문 제안 금지 · **발행 금지(C등급)** · 정본(편 폴더·발행로그·소재큐) 직접 쓰기 금지.
- **어미 불변**: 카드 문장은 해요체 그대로, 캡션성 문장은 존댓말 그대로(§4.1). 변환하며 어미를 통일하지 않는다.
- 새 주장·새 수치를 만들지 않는다 — 소스 맵에 없는 문장은 존재할 수 없다.

**GATE** (구현 승인 대상 — `epcheck` 확장이 아니라 별도 `distcheck.py`)
- ⓐ 변환본 ↔ FACTS: `cardcheck.assert_kit_facts` 의 «변환본 판» — 변환본에 적힌 사실 수치가 전부 `numeral_vocab()` 안(guard 3 확장). 역검증: 수치 하나를 `720.7` 로 바꿔 걸리는지.
- ⓑ 어미: epcheck `[3]` 의 `haeyo`/`polite` 를 그대로 호출. 역검증: 합쇼체 한 줄 심기.
- ⓒ 장수·길이: Threads ≤20 · X ≤4 · 장당 글자 상한(채널 실측값으로 채운다 — 미실측이면 `확인 불가` 로 두고 FAIL 아님).
- ⓓ 링크 위치: X 본문에 URL 0건, 답글 블록에 킷 URL = `KIT["url"]` 1건.
- ⓔ 소스 맵 완결: 변환본 문장 수 = 소스 맵 행 수.

**성공지표** JJ 가 변환본을 **수정 없이 발행한 비율** ≥ 70% (5편 누적 후 판정). 측정: 발행본 vs 초안 diff 줄 수 0.

**FAIL CONDITION** 소스 맵을 못 만든 경우(`_facts.py` 없음) · GATE ⓐ/ⓑ/ⓓ/ⓔ 중 하나라도 FAIL · 리포트 파일을 못 쓴 경우. 장수 초과는 FAIL 이 아니라 «부분» 표기(정관 §4).

**6질문 답**
① 의존 소스: 편 선언·FACTS(정본) · 덱 실물 · 채널 제약 문서. ② 충돌 승자: 편 폴더는 읽기만 — 충돌 없음; 리포트 파일은 워커가 유일 작성자. ③ 필요 컨텍스트: SKILL §4.1·§5·§6.1·v3.52 · 설계안 §1·§2. ④ 금지 컨텍스트: 타 편 폴더 · 메모리 · 스캔로그. ⑤ 반복 교정: 어미·길이 교정 → R4(SKILL) / 소스 맵 오류 → R6(distcheck). ⑥ 교정→규칙: 같은 압축 교정 3회면 «압축 규칙» 을 SKILL §5 에 신설.

**하네스 판정** 봇 메모리 = **부채**. 편마다 독립이고 정본이 편 선언에 있다 — 기억할 것이 없다. off.
