# 헤르메스 ⑦ 훅 브레인스토머 — 양식 4 · 층: 제안 · 상태: 설계 (2026-08-26)

**JOB** 편 기획안(축·주체·사실 8건 이내)을 받아 표지 훅 후보 **N=12** 를 내고, **pre-flight ①(훅 고유명사 `assert_cover_nouns`)·폭 검사(`epcheck` 표지 줄 폭 로직)** 로 1차 거른 뒤 통과분만 사람에게 준다. 고르는 것은 사람이다.

**TRIGGER** 사람 호출 — SKILL §7 제작 순서 4번(기획·집필) 안. ep31 에서 훅 규격 위반(고유명사 0)이 «만든 뒤» 잡혀 표지를 재조립한 재작업이 계기다(파이프라인 감사 §6).

**INPUTS** 기획안(사본) · `COVER_NOUNS`(편 선언) · SKILL §4.1(반말 훅 허용) · §6 0.5초 룰 · v3.51 «훅 말미 물음표 허용 · 레퍼런스 4항 ②(숫자는 그림이 받는다)» 발췌 · 폰트 크기 후보(76/68).

**PROCESS** 1. 후보 12개(2줄 훅, 각 줄 ≤ 폭) 2. `preflight` ① 로 고유명사 없는 것 제거 3. `epcheck` 표지 폭 로직(`template.cover_layout` 실측)으로 넘치는 것 제거 4. 통과분 + 탈락 사유 표 → `reports/<날짜>_hooks_epNN.md` + `STATUS:`.

**OUTPUT** 리포트 1건. `build_epNN.py` 쓰기 금지(훅 확정은 사람이 선언에 적는다).

**RULES — 금지 자리** 훅 확정 금지 · 조문 제안 금지 · 발행 금지 · 정본 직접 쓰기 금지 · **사실 8건 밖의 말 금지**(v3.47 — 훅이 미검증 함의를 만들면 그 편의 위험이다: 탈락 사유 «사실 밖» 을 둔다).

**GATE** 통과분 전부가 pre-flight ①·폭 검사 OK 인가(리포트에 검사 로그 동봉). 역검증: 고유명사 없는 훅 1개를 후보에 심어 탈락 표에 나오는지.

**성공지표** keep rate = 사람이 고른 훅이 후보 안에 있었던 편 ÷ 시범 편 ≥ 50% (편 4건 이상). 부수: 후보 중 pre-flight 통과율(낮으면 발상 규칙 문제).

**FAIL CONDITION** 기획안·`COVER_NOUNS` 없음 · 통과분 0건도 FAIL 아님(«0건 — 발상 실패» 표기).

**6질문 답** ① 기획안·선언(사본) + 검사 코드(정본 호출) ② 리포트 유일 작성자 ③ §4.1·§6 0.5초 룰·v3.51 발췌·`COVER_NOUNS` ④ 메모리 · 타 편 훅(전 편 훅을 보면 변주가 아니라 복제가 나온다) · 검증로그 전문 ⑤ 탈락 사유 반복 → R4(훅 규격) 또는 R6(pre-flight 항목) ⑥ 같은 탈락 사유 3회 → pre-flight 항목 신설 제안.

**하네스 판정** 봇 메모리 = **부채(off)**. **채점** 반복 1 · 시간 1 · 검증 2(pre-flight 전수) · 실패 비용 2 · 오염 2 = **8/10**.
