# 헤르메스 ⑥ 유통 변환 초안 — 양식 4 · 층: 제안 · 상태: 설계 (2026-08-26)

**JOB** 유통 변환 워커(`distribution-transform.md`)의 **초안 공급자**. 소스 맵이 붙은 Threads 20장·X 4장 초안을 만들어 `distcheck` 를 통과시킨 뒤 넘긴다. 워커 5 가 «무엇을 검사하고 누가 발행하나» 를 정하고, ⑥ 은 «초안을 누가 쓰나» 만 맡는다.

**TRIGGER** 사람 호출(워커 5 와 동일 — 발행 확정 후).

**INPUTS** **발행 완료 편의 공개본만** — 카드 텍스트(헤드라인·핵심줄·본문)·캡션·고정 댓글·덱 실물(전부 이미 공개된 것) + 채널 제약 수치(장수·글자 상한). **`_facts.py`·편 선언 원문·검증로그는 투입 금지**(공통 원칙) — 소스 맵(주장→FACTS 키)은 **워커 5 가 로컬에서** 붙인다; ⑥ 은 «어느 문장을 어느 장에» 만 정한다. 레포 접근 없음.

**PROCESS** 워커 5 PROCESS 1~5 를 수행하되 6(GATE)은 **워커 5 가 돌린다** — 초안 작성과 검수를 한 컨텍스트에 두지 않는다(SKILL v3.50 게이트 운용 1항).

**OUTPUT** 초안 파일 `reports/<날짜>_dist_epNN.draft.md`. 발행 금지 · 정본 쓰기 없음.

**RULES — 금지 자리** 게이트 판정 금지 · 조문 제안 금지 · 발행 금지 · 정본 직접 쓰기 금지 · 새 주장·수치 금지(소스 맵 밖 문장 0건) · 어미 변경 금지.

**GATE** `distcheck.py` ⓐ~ⓔ (워커 5 명세) — 워커 5 가 실행. ⑥ 자체 GATE 는 «소스 맵 행 수 = 문장 수» 하나(자기 산출 형식 검사).

**성공지표** keep rate = `distcheck` 1회 통과 초안 ÷ 낸 초안 ≥ 50%(시범) → 70%(가동). 부수: JJ 수정 줄 수.
