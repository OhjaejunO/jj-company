# backlog-curator — 양식 4 · 층: **감시** · 상태: **설계 (구현 미승인)**

> 🔴 **이 문서는 설계만이다. 구현·스케줄 등록은 별도 JJ 승인 대상이다.**
> 레퍼런스 ③(Hermes Curator) 규격을 그대로 따른다 — **삭제 없음 · 스냅샷 선행 · pin.**
> A 작업 5번(레퍼런스 §3-A)의 산출물.

## 왜 필요한가

**쌓임은 강한데 소비 장치가 없다** (설계도 §3-1). 2026-08-31 실측:

| 목록 | 건수 |
|---|---|
| `docs\clause-backlog.md` C 항목 | **38** |
| `docs\infra-backlog.md` 항목 (`### ` 머리) | **26** |
| C-27 안의 JJ 판정 대기 | **7** |
| `docs\learnings.md` | **13** |

레퍼런스 ①의 진단이 이 자리다 — 「선별된 원자 사실 50개가 방치된 조각 5만 개를 이긴다」.
🔴 **지금 위험은 «잃는 것»이 아니라 «안 읽는 것»이다.** 그래서 이 워커는 **아무것도 지우지
않는다** — 하는 일은 **«무엇이 오래 안 읽혔는가»를 눈에 보이게 만드는 것**뿐이다.

## OWNS (소유)

`docs\clause-backlog.md` · `docs\infra-backlog.md` · `docs\learnings.md` 의 **읽기와 표시**.
🔴 **본문 수정은 소유하지 않는다.**

## PROCESS (순서)

1. **스냅샷 먼저.** 세 파일을 `logs\curator\<날짜>\` 에 그대로 복사한다. 🔴 **표시를 붙이기
   전에** 뜬다 — 순서가 뒤집히면 «표시 붙은 판본»이 스냅샷이 되어 원본을 잃는다
   (정관 §0 «검사는 쓰기 전에 한다»).
2. **마지막 참조일을 잰다.** 각 항목 번호(`C-NN`·`### NN.`·`L-NNN`)를 **레포 전체 + git log
   메시지**에서 찾아 **가장 최근 커밋 날짜**를 그 항목의 «마지막 참조»로 본다.
   🔴 **자기 파일 안의 언급은 세지 않는다** — 그러면 모든 항목이 «오늘 참조됨»이 된다.
3. **30일 넘게 참조 0인 항목을 `stale` 로 표시**한다. 표시는 **제안 리포트에만** 적는다.
4. **`pin` 된 항목은 표시하지 않는다.** 항목 본문에 `<!-- pin -->` 이 있으면 건너뛴다 —
   판정 대기라 오래 머무는 것이 정상인 항목(C-27 계열)이 매주 걸리면 리포트가 소음이 된다.
5. **리포트를 쓴다**: `reports\<날짜>_backlog-curator.md` — stale 목록 · 목록별 건수 추이 ·
   pin 현황 · **«20건 초과» 문턱 경보**(A 작업 6번).
6. `STATUS: OK` / 데이터를 못 읽었으면 `STATUS: FAIL <사유>`.

## GOOD OUTPUT (좋은 산출은 어떻게 생겼나)

- stale 목록에 **항목 번호 · 제목 · 마지막 참조일 · 며칠째**가 있다.
- «지우자» 라고 쓰지 않는다. **«이 항목이 30일간 아무 데서도 안 불렸다»** 가 전부다.
- 건수가 지난주와 같으면 **같다고 적는다.** 변화 없음도 값이다.

## UNCERTAIN (불확실할 때 — ⑮ 3부)

- **항목 번호를 못 찾겠으면 «판정 불가» 로 적는다.** 번호 체계가 셋(`C-NN`·`### NN.`·`L-NNN`)
  이라 정규식이 놓칠 수 있고, **놓친 것을 «참조 0» 으로 적으면 거짓 경보**가 된다.
- **git log 를 못 읽으면 그 회차는 `STATUS: FAIL`** 이다. 부분 데이터로 stale 을 판정하지 않는다.

## STOP (정지선 · 사전 정지 조건 — ⑮ 퓨즈)

🔴 **불나기 전에 정한다** (A 작업 7번 · C-37):

1. **stale 이 한 회차에 전체의 40% 를 넘으면 멈추고 보고**한다 — 그건 백로그가 아니라
   **참조 탐지가 고장난 것**이다(정규식·경로 변경).
2. **어떤 이유로도 세 파일을 수정하지 않는다.** 수정이 필요하면 리포트에 적고 사람이 한다.
3. **스냅샷 실패 시 그 회차는 아무것도 하지 않는다.**

## 등급 · 권한

**A등급 (완전 자동 · read-only).** 도구는 `Read`·`Glob`·`Grep`·`Write`(리포트만).
🔴 **`Edit` 를 주지 않는다** — 본문을 못 고치는 것이 이 워커의 성질이고, 그것은 말이 아니라
도구 목록으로 지킨다(정관 §0 4층 ①).

## 🔴 이 설계가 못 하는 것 (정관 §0 4층 ④)

| 못 하는 것 | 왜 |
|---|---|
| «이 항목이 아직 유효한가» 판정 | 의미 판정이다. 참조 빈도는 **유효성의 대리 지표일 뿐**이고, 옳지만 아무도 안 부르는 조문이 있다 |
| 중복 항목 탐지 | 같은 내용이 두 번호에 있는지는 문장 뜻을 봐야 안다. 8/25 재고에서 33건 중 4건이 **이미 등재된 것**이었는데 그것은 사람이 찾았다 |
| 판정 대기의 «지연» 판정 | 며칠 대기했는지는 세지만 **그게 문제인지는 JJ 만 안다.** 그래서 경보가 아니라 표시다 |
