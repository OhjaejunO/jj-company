# 크로스 모델 검수 체크리스트 (공개 가능 · 20줄 이내 · 헤르메스 ① 입력용)

이 목록은 SKILL 조문의 원문이 아니라 «발행 예정 텍스트가 지켜야 할 것»을 공개 가능한 말로 다시 쓴 것이다. **JJ 승인 확정 (2026-08-26, C1~C12).** 항목 번호는 검수 봇의 지적 근거로 쓰인다. 개정은 JJ 승인 후 PR.

- C1 카드 헤드라인·본문·핵심줄은 해요체다. «…입니다/…됩니다» 같은 합쇼체는 카드에 쓰지 않는다. (표지 훅은 반말 허용)
- C2 캡션·고정 댓글은 존댓말(합쇼체)이다.
- C3 카드 본문은 내용만 말한다 — 출처 언급(«공식 발표 기준이에요», «X에 올린 말도»)과 제작 과정 자기 언급(«우리가 그린»)은 쓰지 않는다.
- C4 «~는 없습니다», «이게 전부입니다» 같은 부재 서술은 카드에 쓰지 않는다. 다루지도 않은 주제에 «확인하지 않았습니다»라고 적지 않는다(다룬 주제의 미확인 표기는 허용).
- C5 캡션·고정 댓글에 다음 편 예고를 쓰지 않는다. 고정 댓글의 결은 팔로우 결 하나다.
- C6 같은 수치는 카드·캡션·킷에서 같은 값이다. 값이 같아도 비교의 방향(A가 B보다 크다/작다·증가/감소·긍정/부정)이 뒤집히면 지적한다.
- C7 시점이 붙어야 하는 수치(조회수·별·가격)에는 조회 시점이 있다.
- C8 표지 훅에는 소재의 고유명사가 최소 하나 있다.
- C9 캡션 첫 줄은 표지 훅 문장과 같다.
- C10 캡션에 URL·구분선·제작 과정 서사가 없다. 해시태그는 캡션 5개, 고정 댓글 5개 이하, 겹침 없음.
- C11 카드 한 장은 한 생각이다. 헤드라인이 말하는 것과 본문이 말하는 것이 다르면 지적한다.
- C12 킷 본문의 사실 수치는 카드·캡션의 수치와 모순되지 않는다.

출력 규칙: 지적은 «[C번호] 자리(카드 번호·줄 / 캡션 / 고정 댓글 / 킷) — 무엇이 — 왜» 한 줄씩, 최대 10건, 중요한 순. 근거 번호 없는 지적은 내지 않는다. 지적이 없으면 «지적 0건»이라고만 쓴다. 판정(통과/실패)은 내지 않는다 — 그것은 게이트와 사람의 몫이다.
