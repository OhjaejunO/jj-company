# 네이버 블로그 «AI 뉴스» 초안 형식 (정본 · 2026-09-05)

> 왜 이 꼴인가 — `reports\2026-09-05_naver-ai-blog-benchmark.md` §4·§5. 상위 블로그 31편 실측:
> 첫 문단 요약 → Q. 소제목 → 표 → FAQ → 참고 출처 → 해시태그 5~15, 2,500~3,900자, 이미지 7장, 1인칭 한 줄.
> 완전 자동 매일 3편(8,000자·이미지 1장·해시태그 35)은 두 달에 방문 2,045 — 그 꼴의 반대로 간다.
> 재는 것은 `scripts\blogcheck.py`. 여기 적힌 것과 검사가 갈리면 **검사가 정본**이고 이 문서가 틀린 것이다(정관 §0).

## 파일

`reports\blog\<YYYY-MM-DD>_<짧은 이름>.md` · UTF-8 · 프런트매터:

```
---
kind: daily | weekly
date: YYYY-MM-DD
source: <스캔로그 날짜 · 편 이름>
status: draft | ready
---
```

## 절 (순서 고정 · 전부 필수)

1. `# 제목` — 연월·주차 또는 «총정리/소식/브리핑» 낱말. 예: «오늘의 AI 소식 3가지 - … (2026년 9월 8일)».
2. `## 요약` — 2~5문장. AI 브리핑이 뜯어가는 자리. 무엇이 언제 나왔고 누가 쓸 수 있는지.
3. `## 본문` — `### Q. …` 소제목 2개 이상. 소식마다 **굵은 첫 문장** + 2~3문장 + `(출처: 도메인 · YYYY-MM-DD)`. 표(`|---|`) 1개 이상 — «이번 주 한눈에» 같은 비교표.
4. `## FAQ` — `**Q. …**` 3문답. 확인 못 한 것은 «확인 못 했어요».
5. `## 토망치랩 한마디` — 초안은 `[[JJ 한마디]]` 그대로. **JJ 가 2문장(≤3)** 을 넣는다. 기계가 채우면 게이트 FAIL.
6. `## 관련글` — 인스타 카드 URL ☞ 1~3 + 채널 안내 한 줄 + '토망치' 키워드 안내.
7. `## 이미지` — `N. \`경로\` — 설명 (출처: …)` 3~6장. 우리 덱 카드·공식 og 만.
8. `## 태그` — `#태그` 5~15개.

## 길이

- 일간(daily): 소식 3~5건 · 요약+본문 2,500~3,500자(공백 제외).
- 주간(weekly, 일요일): 낸 편 + 새 소식 · 2,000~5,500자.

## 금지

- 발표 행위 서술(발표했어요·공개했어요·출시했어요·밝혔어요) → «나왔어요».
- 자기 서술(저희가 검증·검증했어요·AI가 작성) · 편 번호(ep44) · 과장(드디어·혁신·역대급·완벽하게).
- 인스타 캡션 문장 복붙(20자 이상 같은 문장) · 캡션 CTA 되풀이.
- 브리프에 없는 사실·URL.

## 발행 (C등급 · JJ)

1. `[[JJ 한마디]]` 를 2문장으로 바꾼다 → `status: ready`.
2. `py scripts\blogcheck.py <파일> --publish` 가 OK.
3. 네이버 스마트에디터에 제목·본문·이미지·태그를 붙인다(표·소제목은 첫 편에서 살아남는지 실측).
4. 발행 URL·시각을 회신 → 스코어카드 «블로그» 칸(인용수는 JJ 조회값만).
