# 보안 알림 판정 원장

> **이 파일이 보안 알림 판정의 정본이다 (2026-08-25 신설, 정관 §2).**
> 자동 보안 리뷰·deny 규칙 발동·스캐너 경고가 오면 **먼저 이 원장을 본다.** 같은 알림이 이미 판정돼 있으면 그 판정을 인용하고 끝낸다 — 다시 조사하지 않는다.
> 없으면 조사한 뒤 **한 줄 추가**한다. 판정은 «오탐 / 정탐 / 확인 불가» 셋 중 하나이고 근거는 커밋·파일·실측이어야 한다.
>
> **왜** — 2026-08-25 자동 보안 리뷰가 `.claude/settings.json` 의 `permissions.deny` 12건을 allow 로 오독해 «자격증명 경로 허용» 으로 올렸다. 기록할 자리가 없어 **두 세션이 같은 조사를 두 번**(13:24 · 13:35) 했고 결론도 같았다(오탐). 두 번째부터는 원장 한 줄이면 된다.
