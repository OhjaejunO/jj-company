# 씬 개념 부름말 매칭 규칙 — 재검토 안 (2026-08-27)

> **성격**: 설계안. **구현은 별건 JJ 승인.** 오늘 «개방» 이 «무료 개방» 을 삼킨 사고에서 나온 것이고, 급한 불(그림자 2건)은 이미 키워드 조정으로 껐다(content-ops #8). 이 문서는 **규칙 자체를 바꿀지**를 다룬다.

## 1. 지금 규칙과 그 대가

`_concept_key(concept)` 는 부름말을 **부분 문자열**로 찾고 **먼저 선언된 개념이 이긴다.**

```
"무료 개방" 을 찾을 때  →  free-open 의 키워드 «개방» 이 부분 문자열로 걸린다  →  free-open 승
                          (뒤에 선언된 free-lane-more-items 의 «무료 개방» 은 도달 불가)
```

- **좋은 점**: 「무료 개방 이벤트」·「기간이 겹침」처럼 **말이 조금씩 달라도 잡힌다.** 개념 라이브러리는 사람이 자연어로 부르는 자리라 이 관용이 값을 한다.
- **대가**: 개념이 늘수록 **짧은 키워드가 긴 키워드를 삼킨다.** 오늘 실측 — «개방» ⊃ «무료 개방», «free» ⊃ «free-lane», «preview» ⊃ «architecture-preview». 셋 다 **조용히** 다른 씬을 돌려줬다.
- 지금은 `self_test()` 의 그림자 검사가 잡지만, **그것은 사후**다. 등재하는 사람은 «내 키워드가 남의 것을 삼키는지»를 매번 생각해야 한다.

## 2. 안 셋 (택일 또는 조합)

### 안 A — 경계 매칭 (권장)
부분 문자열 대신 **토큰 경계**로 맞춘다. `"무료 개방"` 은 «개방» 과 매칭되지 않고, `"개방 이벤트"` 는 «개방» 과 매칭된다.
- 구현: 한국어는 공백·조사 경계, 영어는 `\b`. 실무적으로는 «부름말이 입력의 **어절 경계에서 시작·끝나는가»** 로 충분하다.
- 얻는 것: 오늘 사고 3건이 **규칙 차원에서 사라진다.**
- 잃는 것: 「무료개방」(붙여 쓴 경우)·「개방된」(활용형)이 안 잡힌다 → **부름말을 여러 개 등재**해 메운다(이미 그렇게 쓰고 있다).
- 위험: 기존 호출 중 부분 문자열에 기대던 것이 깨질 수 있다 → **전수 재측정이 필요하다**(현행 26개념 × 등재 부름말 전부를 넣어 결과가 바뀌는지 대조).

### 안 B — 최장 일치 (longest match wins)
선언 순서 대신 **가장 긴 부름말이 이긴다.** «무료 개방»(5자)이 «개방»(2자)을 이긴다.
- 얻는 것: 오늘 사고 3건이 전부 뒤집혀 **의도한 개념**으로 간다. 기존 관용(부분 문자열)은 그대로.
- 잃는 것: 순서가 판정에 안 쓰이므로 «먼저 선언이 이긴다»를 아는 사람의 직관이 바뀐다. 같은 길이 충돌은 여전히 순서로 가른다.
- 위험: 낮다. **이 안이 가장 적은 변경으로 오늘 사고를 없앤다.**

### 안 C — 명시 우선순위
개념에 `priority` 를 두고 충돌 시 그것으로 가른다.
- 얻는 것: 판정이 눈에 보인다.
- 잃는 것: **사람이 매번 값을 정해야 한다.** 개념이 26개인 지금도 부담이고, 안 적으면 기본값 싸움이 다시 순서로 돌아간다. **권하지 않는다.**

## 3. 권고

**안 B(최장 일치)를 먼저, 안 A(경계 매칭)는 그 뒤에 실측으로 판단한다.**
B 는 한 줄 수준의 변경이고 오늘 유형(짧은 말이 긴 말을 삼킴)을 **구조적으로** 없앤다. A 는 더 깨끗하지만 활용형·붙여쓰기에서 못 잡는 것이 생겨 **부름말 표를 손봐야** 하므로, B 로 사고를 없앤 뒤 «그래도 잘못 잡히는 것»이 남는지 보고 결정한다.

**어느 쪽이든 함께 할 것**
- `self_test()` 의 그림자 정의를 새 규칙에 맞춰 고친다(최장 일치면 «짧은 것이 긴 것을 가림»이 더 이상 그림자가 아니다 — **검사가 옛 규칙을 재면 그때부터 헛돈다**, 정관 §0).
- **전수 재측정**: 현행 26개념의 모든 부름말을 `_concept_key` 에 넣어 **바뀌는 결과를 표로** 낸다. 하나라도 바뀌면 그 개념을 쓰는 편의 실물을 확인한다(발행분은 소급하지 않는다).
- 등재 절차 문서(`scenes.py` 주석)의 «먼저 선언이 이긴다» 문장을 같이 고친다 — 안 고치면 코드와 주석이 갈린다.
