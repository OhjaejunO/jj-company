# 판정기록 — 주간 keep / test / stop

> [[성과대장]]을 근거로 낸 제안과 JJ 판정. **승인된 것만 효력이 있다** — 제안 상태로는 아무것도 바꾸지 않는다.
> 제안은 근거 행(편·측정일)을 명시한다. 근거 없는 제안은 이 파일에 들어오지 못한다.
> 한 번 강하게 나온 결과는 **가설(test)이지 규칙(keep)이 아니다** — keep 은 반복 확인을 요구한다.

## 형식

```
## YYYY-MM-DD
- keep: <패턴> — 근거: <성과대장 행들> — 판정: 승인/기각/보류 (JJ, 날짜)
- test: <가설과 다음 실험> — 근거: … — 판정: …
- stop: <중단할 패턴> — 근거: … — 판정: …
```

---

(아직 판정 없음 — 첫 판정은 도달 데이터 첫 수집 뒤에 한다. 데이터 없이 판정하지 않는다.)
