# /srv/creator — 크리에이터 팀 작업 폴더

이 폴더는 **봇 다섯이 같이 쓰는 자리**다. 사람도 읽는다.

```
BRIEF.md   지금 무엇이 있는가 (실측값 + JJ 만 아는 빈칸)
소재/      research — 사실과 출처
기획/      lead — 무엇을 언제 · 누구에게
원고/      writer — 원고 · editor 의 <원고>.검수.md 가 옆에 붙는다
성과/      growth — 결과와 다음 실험
```

## 규칙

- **남의 칸에 쓰지 않는다.** 다섯이 같은 폴더를 쓰므로 나중 쓰기가 앞의 것을 지운다.
- **파일 이름은 `YYYY-MM-DD_<무엇>.md`.** 날짜가 앞이라 저절로 정렬된다.
- **추측을 적지 않는다.** 확인 안 된 것은 「확인 불가」다 — 다섯이 서로의 파일을
  사실로 읽으므로 지어낸 한 줄이 원고까지 간다.

## 이 폴더가 아닌 것

- `/srv/company` — 회사 레포 미러다. 다른 봇들(plan·dev·review·ops·marketing)의 자리다.
  **읽어도 되지만 쓰지 않는다.**
- `/srv/obsidian` — JJ 의 세컨드브레인 사본. **읽기 전용이다.**

## 백업

`/usr/local/bin/buzz-backup` 이 매일 이 폴더를 `/srv/backups/buzz` 에 넣는다(14일 보관).

남길 가치가 생긴 산출물은 JJ 가 레포나 드라이브로 뺀다.
